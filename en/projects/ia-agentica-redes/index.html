PROJECT 2

Agentic AI on 4G and 5G networks: network services requested in natural language

An AI agent offers services on 4G and 5G networks that are configured and deployed with natural language, using the CAMARA network APIs: alerts when an older person or a child leaves an authorized area, payments authorized only when the phone is verified inside an allowed zone, quality on demand for a video call, and population density data for emergencies or events.

In the project's design, the agent and the APIs run on a telco cloud that follows the Sylva guidelines (Linux Foundation Europe): Kubernetes clusters managed with Cluster API, Git changes that Flux applies, and network functions as containers.

Tracking a person's location requires their consent (in CAMARA, the line holder's authorization). This is a proposed design: it does not claim these services are available in Colombia today, or that any operator deploys 4G or 5G networks from natural language.
